CellVision AI

Advanced AI-powered dashboard for researchers and medical professionals to analyze, classify, and visualize cell images using cutting-edge deep learning and computer vision technology.

🔬

Single Image Prediction

Upload a cell image for instant benign/malignant classification with confidence scores and detailed analysis.

📊

Batch Analysis

Upload CSV files containing multiple images for large-scale predictions, view result distributions, and export comprehensive batch results.

📈

Metrics & Evaluation

Upload ground-truth labels to generate detailed metrics, confusion matrices, and comprehensive performance reports.

🖼️

Example Images

Browse random samples of benign and malignant cell images for reference and educational purposes.

🛠️

OpenCV Tools

Apply and visualize advanced image processing and augmentation techniques:

  • Grayscale conversion
  • Gaussian Blur & Canny Edge Detection
  • Adaptive Threshold & Contour Detection
  • CLAHE Enhancement
  • Image Rotation & Flip Operations
  • Gaussian Noise Addition
🔢

Cell Counting

Automated cell counting and size distribution analysis for microscopy images with precise measurement capabilities.

⏱️

Time-lapse Analysis

Track and analyze cell count changes across sequences of images for temporal studies and growth pattern analysis.

📝

Session History

Access and export all predictions and results for reproducibility, audit trails, and research documentation.

🧠

Model Information

View detailed information about the ResNet-18 model architecture, training datasets, and latest performance updates.

🤖

Researcher Chatbot

Ask medical research questions and receive expert answers via integration with PubMed and Gemini APIs for comprehensive research support.

📥 Getting Started

1

Clone Repository

Get the source code from GitHub

git clone https://github.com/<username>/cellvision-ai.git
cd cellvision-ai
2

Install Dependencies

Install all required Python packages

pip install -r requirements.txt
3

Run Application

Start the Streamlit dashboard

streamlit run app.py
4

Access Dashboard

Open your browser and navigate to the local server

http://localhost:8501
